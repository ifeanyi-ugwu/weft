# @weft/docs

The Weft documentation site, built with [Astro Starlight](https://starlight.astro.build).

```sh
pnpm dev     # http://localhost:4321
pnpm build   # static site in dist/
```

Pages live in `src/content/docs`. Colours map to the brand tokens in `src/styles/theme.css`. The site URL is set in `astro.config.mjs` (`site`); change it when the docs move to their own domain.
